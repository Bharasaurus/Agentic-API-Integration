## Quick Start

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

### 2. Configure Environment

The `.env` file is pre-configured with defaults:
```
PET_SERVICE_BASE_URL=http://localhost:8001
HTTP_TIMEOUT_SECONDS=10
```

### 3. Run Tests

```bash
python -m pytest test_endpoints.py -v
```

**Result:** All 6 tests pass ✓

### 4. Run the Application

**Option A: With Mock Backend**
```bash
python quickstart.py
```
This starts both the mock pet service (port 8001) and the main API (port 8000).

**Option B: Just the API**
```bash
uvicorn main:app --host 127.0.0.1 --port 8000
```

### 5. Test Endpoints

Once running, test the API:

```bash
# Create a pet
curl -X POST http://localhost:8000/pets \
  -H "Content-Type: application/json" \
  -d '{"content": "Fluffy the cat"}'
```

**Response:** `201 Created`

### 6. View API Documentation

- **Swagger UI:** http://localhost:8000/docs
- **ReDoc:** http://localhost:8000/redoc

## API Endpoints

### POST /pets
Create a new pet

**Request:**
```json
{
  "content": "string (required, non-empty)"
}
```

**Responses:**
- `201 Created` - Pet created successfully
- `422 Unprocessable Entity` - Validation error (empty content, missing field, etc.)
- `502 Bad Gateway` - External service unavailable

## Extending the Code

### Add a New Endpoint

1. Update `models/pet.py` with new request/response models
2. Add routes to `routers/pet_router.py`
3. Add corresponding client methods to `clients/pet_client.py`
4. Add tests to `test_endpoints.py`

### Change the External Service URL

Set the environment variable:
```bash
export PET_SERVICE_BASE_URL=https://api.example.com
python quickstart.py
```

## Troubleshooting

**ImportError: cannot import httpx**
- Install: `pip install httpx`

**Connection refused to Pet Service**
- Ensure mock service is running (port 8001)
- Or update `PET_SERVICE_BASE_URL` in `.env`

**Pydantic validation errors**
- Ensure JSON request body matches the schema
- All required fields must be present
- `content` field cannot be empty
